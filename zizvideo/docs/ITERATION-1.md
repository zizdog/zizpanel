## 逐条要求

**1 静音按钮**：单击画面不再切静音；改成画面角落一个 🔊/🔇 按钮，点它切静音（记住用户选择，localStorage）。
**2 单击画面 = 暂停/继续**：单击画面切换播放/暂停，显示中央 ▶/⏸ 提示（300ms 淡出）。
**3 进度可拖动**：进度条可点击/拖动 seek（鼠标 + 触摸），拖动时显示时间气泡；松手后 `currentTime` 生效并**立刻 PATCH 进度**。
**4 默认随机播放**：进入播放页默认即为随机顺序（见 6 的随机实现）。
**5 上滑过渡 + 跳两个的 bug**：
   - 过渡生硬 → 用 CSS transform 做位移动画（`transition: transform .28s ease-out`），禁止用 scroll-snap 硬跳；
   - **短内容一次跳两条**根因多半是"滚轮/触摸事件在一次手势里触发了多次切换" → 加**手势锁**（一次手势只允许切一条，`isAnimating` 或时间阈值 400ms），并保证 `IntersectionObserver` 的回调不叠加。**必须写门禁**覆盖"一次手势只前进一条"。
**6 无限滑动 + 播完前不重复**：随机用 **seed + hash 排序**实现（`ORDER BY hash(id||seed)`），每用户持久化 `feed_seed` 与已播计数；**未播完不重复**；全部播完后换新 seed 进入下一轮。翻页游标沿用现有 `next_cursor`。
**7 循环与自动播设置（二级菜单）**：播放页右上放 ⚙ 图标 → 弹出二级设置：`循环播放`（**仅在非连播/非自动播时生效**）、`自动播放下一个`（默认开）。设置持久化到后端（每用户）。
**8 管理员可开关注册**：配置项 `allow_register`（默认**关**）；关时 `/api/v1/setup|register` 之外的注册入口一律 404/403 并如实说明；管理页给开关 + 生效值回读。
**9 剧场（短剧）**：新增实体 `series`（id/标题/简介/封面/库归属/排序）+ `series_media`（剧集顺序）。
   播放逻辑：剧场页列出剧集 → 点进某剧 → **按序连播**（自动下一集、可手动选集）、显示"第 N 集"、返回键回到剧场列表；
   剧集内容**引用已有 media**（不复制文件、不新上传）；管理端可"新建剧场 + 把媒体加入某剧场并排序"。
   **必须写清设计**（表结构、接口、连播状态机、与 6 的随机不冲突：剧场内是顺序，不吃随机 bag）。
**10 底栏**：播放页底部四入口「首页（当前播放页）/剧场/收藏/我的」；「收藏」页三个 Tab：**点赞 / 收藏 / 历史**，
   每个 Tab 都可**清除记录**（二次确认，后端 DELETE 接口，如实报清了多少条）；「我的」= 账号、设置入口、退出登录。
**11 媒体去重（管理员）**：判据先用 `(size_bytes, duration_ms)` 分组（同组疑似重复），列出组内成员（路径/库/时长/加入时间）；
   默认只提供**删除面板记录**（不动磁盘文件），要删文件必须**单独勾选 + 手输确认**（危险动作，走任务中心 + 实时进度）。
   **绝不自动删**；检测结果要标明判据，别声称"内容完全相同"。
**12 管理页返回播放页入口**：管理页顶部固定一个「返回播放」按钮（返回首页/播放页）；键盘 Esc 也返回。
**13 播放页显示所属媒体库**：视频信息区显示"来自 <库名>"，**点击**把 feed 范围切到该库（并给"全部库"的返回入口）。
