      OpenAI 兼容接口
      
POST /v1/audio/transcriptions        （multipart/form-data）
  file=@audio.wav  model=large-v3-turbo  language=zh  response_format=srt

GET  /v1/models                     装了哪些档、当前档是谁
GET  /healthz                       能力探活（模型在 + 引擎在 + 真的转一次）
POST /v1/models/<id>/download       下载某一档（202 + task_id）
POST /v1/models/<id>/delete         删除某一档（需 {"confirm":true}）

curl -sS http://127.0.0.1:8892/v1/audio/transcriptions \
     -F file=@/tmp/test.wav -F model=large-v3-turbo -F language=zh \
     -F response_format=verbose_json

      

        超过同步上限（60 秒）的音频会返回
        202 + task_id（进度走 SSE，结果从
        /v1/tasks/<id>/result 取）。
        长音频按 60 秒切片，进度是**真的**（已完成/总片数）。
