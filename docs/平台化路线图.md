## 阶段纪律（提醒我自己）

1. **一次只推一项**：每完成一项 → 更新本表 → 向用户汇报总进度 → **和他讨论下一步**，不擅自扩大范围。
2. **没有证据不算完成**：门禁名 + 本机/真机结论缺一不可；未验证的写"未验证"。
3. **门禁只减不增**：新增门禁必须能失败（负向对照），并且优先替换掉重复的旧门禁。
4. **绝不为了"干净的发布"丢掉用户的改动**（见 `AGENTS.md` 铁律 6）。
5. **涉及真机写操作**（mini / `launchctl` / `sudo`）一律先列命令、经用户点头。
