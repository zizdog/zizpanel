- 真实尝试顺序（`orderDownloadURLs` `:1049-1087`）：
  1. `downloadURLsFor`（`mirror.go:215-226`）先 HEAD `<MB>/apps/<id>/<Tag>/<Asset>` + `manifest.json`；
     都在 → 镜像排第一；
  2. 若镜像排第一 → **不做测速，直接下载**（`:1054-1061`）；
  3. 否则对每个候选 curl 探前 256 KB（`--max-time 6`）再按速度重排（`:1067-1084`）。
- 下载命令：`/usr/bin/curl -fL --retry 1 --connect-timeout 20 --max-time <150 官方 / 300 其余> --speed-limit 1024 --speed-time 30`（`:581-586`），外层 15 min。
  ⚠️ 已知不一致：`--max-time` 按**位置**判定（i==0 → 150 s），镜像模式下镜像排在第一位、却只拿到 150 s，
  且日志把它标成「官方地址」（`:567-578`）。
- 校验：镜像模式用 `<MB>/apps/<id>/<Tag>/manifest.json` 的 sha256（`mirror.go:312-337`，8 s 超时）；
  公网模式用上游 `checksums.txt`（frpc / ddns-go），**orbien-client 上游没有 → `:722-724` 直接 return nil，等于不校验**。
  两者都在解压前做（`:458-471`），另外还有 `file -b` 复核 arm64（`:629-643`）。
- NAS 实测：
  - `frpc/v0.71.0/manifest.json` 声明 `sha256=45be02b186860d375ed49a8941ae9569628a54bf14e67fc36b29c98c99dabcc6`、`size=12680181`；
    我把整包从 NAS 下下来算 sha256 → **完全一致**。
