# 原生应用候选评估（2026-09-21，只调研）

> 回答用户问题：**证件照 / 下载工具 / 聊天服务器 / 音乐服务器 / 笔记 / 相册**，有没有**原生**可用的。
> 本轮**未改任何市场代码、未上架、未发版、未碰 mini**；唯一产物就是这份文档。
> **判据（本项目硬规矩）**：原生 = ① homebrew-core formula（能在 macOS arm64 装）**或** ② 官方 GitHub
> Releases 里真有 `*darwin*arm64*` / `*darwin*aarch64*` 资产。**Docker 不算原生**，单独标「仅 Docker」。
> 每条结论的证据来自本机命令（`brew info --json=v2`、`curl api.github.com/.../releases`、`file(1)`）或上游 URL，
> 时间为 2026-09-21；没查实的一律写「未复核 / 未验证」。上次「HivisionIDPhotos 上架评估」的结论（`2419f84`
> 与 `docs/应用市场下载点清点.md` §现状更新 2026-09-19）**沿用并已复核**，未从零重复。
> 已上架核对：`grep -n 'ID:\|Name:' internal/services/catalog.go` → 本六类里**只有 HivisionIDPhotos、Trilium、
> Immich 已上架（都走 Docker）**，其余候选 `catalog.go` / `market_downloads.go` 里都没有条目。

## 0. 结论先行（六类各一句）

- **证件照：没有像样的原生选项。** 沿用上次结论（HivisionIDPhotos 只能 Docker）；`rembg` 只是「要 Python 的抠图服务」，
  不具备换底/排版能力。→ **保持 Docker，不上原生**。
- **下载工具：原生很成熟。** `transmission-cli`（brew，自带 service 块 + 内建 Web UI）最该先上；`aria2`（brew，RPC 6800）
  作轻量备选；`yt-dlp`（brew）是 CLI、不是常驻服务；qBittorrent 在 macOS 只有 GUI。
- **聊天服务器：原生「能用，但都要收尾」。** 唯一天然常驻的是 brew `ejabberd`（XMPP，erlang/elixir 依赖重）；
  `tinode` 有官方 mac-arm64 二进制但**必须外挂 MySQL/Postgres**；Mattermost / Revolt / Dendrite 无 darwin-arm64 服务端。
- **音乐服务器：原生最佳。** `navidrome`（brew formula + 官方 darwin_arm64 release）最该先上；`gonic`（官方 darwin-arm64
  单文件）作备选；Airsonic-Advanced 已停更、Funkwhale 仅 Docker。
- **笔记：原生最佳。** `memos`（darwin_arm64 release + 单二进制 + SQLite + MIT）最该先上；`silverbullet` 官方也有
  aarch64 server 产物；Trilium 已上架（Docker）；Joplin Server / Outline / Wiki.js 要么 Node+DB、要么仅 Docker。
- **相册：原生有，但都偏轻。** 单二进制只有 `photofield`（MIT，**README 明说无鉴权**）；成熟方案走面板「站点 + PHP」
  的 `Piwigo`（PHP 8.2+ / MySQL）；Immich 已上架（Docker），PhotoPrism / Photoview / LibrePhotos / ente 只发 linux。

## 2. 每类「最该先上」的落地信息

1. **下载 → Transmission**：brew 名 `transmission-cli`（自带 service 块，`brew services start transmission-cli`）；
   安装根由 brew 管，数据/配置 `/opt/homebrew/var/transmission/`（caveats 原文），日志 `/opt/homebrew/var/log/`；
   端口 9091；健康检查 `/transmission/web/`（RPC `/transmission/rpc`）；**有**内建 Web UI；默认
   `rpc-authentication-required: false`、`rpc-whitelist` 只含回环 → 按「三层判据」要写 `PanelInstaller` 落 RPC 口令并回读。
2. **音乐 → Navidrome**：优先走 **release 二进制轨**（brew formula 无 service 块且会拉 ffmpeg+taglib）；
   资产 `navidrome_0.64.0_darwin_arm64.tar.gz`（23,263,336 B，本机实测内层 `Mach-O 64-bit executable arm64`）；
   安装根 `~/navidrome`（面板 release 轨的 `RootDir` 约定，同 alist）；数据 `--datafolder {root}/data`、
   音乐 `--musicfolder <音乐目录>`；端口 4533，**要显式绑 127.0.0.1**（上游默认 `address=0.0.0.0`，源码
   `viper.SetDefault("address","0.0.0.0")` / `port 4533`）；健康检查 `/ping`；**有** Web UI；无默认口令，首次登录自行建管理员。
3. **笔记 → Memos**：资产 `memos_0.31.0_darwin_arm64.tar.gz`（21,058,705 B，内层实测 Mach-O arm64，另有 `checksums.txt`）；
   安装根 `~/memos`；启动 `./memos --port 5230 --data {root}/data`；**必须显式 --port 5230**（代码默认 8081，会撞
   filebrowser）；健康检查 `/healthz`；**有** Web UI；首个注册账号自动成为实例管理员（无默认口令）。
4. **相册 → Piwigo（站点轨）**：官方 `https://piwigo.org/download/dlcounter.php?code=latest`（2026-09-21 实测
   `Content-Length: 19943808`）解压进站点根；要求 PHP 8.2+（面板已有 php82/php84）与 MySQL 5.6+/MariaDB 10.1+
   （面板已有 mysql84/mariadb）；端口=站点端口；健康检查 `/`（首次进 install 向导，向导里建管理员）。
   单二进制备选 **Photofield**：`photofield_v0.25.0_darwin_arm64.zip`，`PHOTOFIELD_ADDRESS=127.0.0.1:8092`，
   数据 `-data`（SQLite），健康 `/`，**无鉴权**，只允许经面板代理访问。
5. **聊天 → Tinode**（接受面板管 DB 的话）：资产 `tinode-alldbs.mac-arm64.tar.gz`；**没有 SQLite**，必须先有
   MySQL/PostgreSQL/MongoDB 之一（面板已有 MySQL/Postgres 条目），再跑 `init-db`；端口 6060（`INSTALL.md`：
   浏览器打开 `http://localhost:6060/` 自测）；配置在 `tinode.conf`。零 DB 的替代是 brew **ejabberd**
   （`brew services start ejabberd`，数据 `/opt/homebrew/var/lib/ejabberd`，端口 5222/5269/5280，Web 管理台 `/admin/`）。
6. **证件照 → 不推荐原生**：保持已上架的 Docker 条目 `hivision-idphotos`（`DockerReference`，端口 7860）。

## 3. 明确「只能 Docker」的（含原因，别再问）

- **HivisionIDPhotos**：上游 Python，无 brew；17 个 release tag 里只有 `pretrained-model` 放了 4 个权重资产，无任何平台二进制。
- **Mattermost**：近 30 个 release 里 0 个 darwin/mac+arm64 资产（官方服务端产物只给 linux，GitHub 只挂 sbom）。
- **Revolt**、**conduwuit/tuwunel**、**Dendrite**（已归档）：发布物只有 linux / 无资产。
- **Funkwhale**：Python + Postgres + Redis，且上游已搬去自建 GitLab，GitHub 仓库 404。
- **Immich（已上架）**、**PhotoPrism**、**Photoview**、**LibrePhotos**、**ente**：官方只发容器 / release 0 资产。
- **MeTube**、**Joplin Server**、**Outline**、**Wiki.js(容器轨)**、**SiYuan(服务端)**、**Trilium（已上架）**。
- 另：**qBittorrent** 不算 Docker 也不算原生服务 —— macOS 官方只有 GUI `.dmg`，没有 nox/无头产物。

## 4. 风险 / 坑

- **端口撞面板保留端口**：memos 代码默认 **8081=filebrowser**；photofield/Airsonic 默认 **8080=IOPaint**；
  silverbullet 默认 **3000=gitea**；Wiki.js 默认 3000。目录门禁要求端口唯一，落地必须显式改端口（上表已给建议值）。
- **鉴权空白，必须绑回环 + 面板代理**：Photofield README 明说 no authentication；Transmission 默认 RPC 无口令；
  gonic 默认 `admin/admin`；SilverBullet 不设 `SB_USER` 就是完全开放。装完必须改口令/设口令并在验收里回读。
- **运行时/依赖成本**：navidrome(brew) 拉 ffmpeg+taglib（ffmpeg 面板已有条目）；ejabberd 拉 erlang+elixir（很重）；
  Synapse/rembg/Funkwhale 要 Python；Piwigo/Lychee 要 PHP+DB；Tinode 必须外挂 DB。这些都不属于「纯填空」。
- **首次外网下载**：rembg 首次运行要下 onnx 模型；Immich（已上架条目）下人脸/CLIP 模型；镜像站目前不覆盖这些模型文件。
- **许可**：AGPL（immich/photoprism/wiki.js/siyuan/metube/ente/funkwhale）、GPL（transmission/aria2/navidrome/gonic/
  tinode/ejabberd/piwigo）、BSL（outline）、Mattermost 混合许可。面板只下载与托管、不改上游，风险低；但若把二进制
  随发布包**分发**，GPL/AGPL 需附源码或许可声明（发布纪律要核）。
- **上游活跃度**：Dendrite archived、Airsonic-Advanced 2024-04 停更、aria2 上游 2023-11 后无 release（brew 仍在维护）、
  Photofield 仅 608 star。选型别只看「有二进制」。
- **校验清单不齐**：memos(`checksums.txt`)/navidrome(`navidrome_checksums.txt`)/photofield(`checksums.txt`) 有；
  gonic / silverbullet / tinode **未见 checksums 资产** → 上架时按 `docs/新增应用工作流.md` 如实填 Checksum，不许假装校验。
- **与已有条目重叠**：Trilium、Immich 已上架；zizvideo 是媒体库不是音乐服务器；alist/filebrowser 不是下载器。

## 5. 未验证项（诚实边界）

- **未做 `file(1)` 的**：photofield / silverbullet / tinode 的 darwin-arm64 资产（本机到 GitHub release 下载约 25 KB/s，
  21–38 MB 包超时）。memos、navidrome、gonic 三件已实测内层为 `Mach-O 64-bit executable arm64`。
- gonic 是否额外依赖 taglib dylib（`go.mod` 用 WASM 版 `go.senan.xyz/taglib`）未实测。
- Tinode 的管理员初始化/首个用户角色、Web 客户端是否随 tarball 一并提供，未实测。
- Piwigo / Lychee 在面板 PHP 8.2/8.4 + MariaDB 上的**真实安装**未做（只核对了上游要求）。
- ejabberd 的管理员注册与 TLS 收尾未实测；MeTube/Ampache 等「未复核」格已在表中标注。
- 未整包验 sha256、未做任何在线审计（`make market-audit`）与真机安装 —— 本轮明确不做，只调研。
